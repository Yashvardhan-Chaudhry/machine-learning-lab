# machine-learning-lab

Coursework, assignments, and experiments from my machine learning studies. A running log, structure grows with the course.

## Contents

- `Numpy And Pandas/` — intro notebooks for NumPy (parts 1 & 2) and Pandas, plus a scratch script.
- `Assignment-1_NumPy_ML/` — NumPy fundamentals: array manipulation, linear algebra, stats, searching/sorting.
- `Data_Collection/` — web scraping (BeautifulSoup) and TMDb API labs. `*_material/` holds instructor notebooks, PDFs and datasets; my own work sits at the folder root.
- `Feature Selection/` — outlier analysis, missing values, chi-square / information gain / t-test feature selection.
- `NLP-labs/` — text preprocessing with NLTK and corpus-to-feature-matrix (TDM variants, tf-idf).
- `Image_Processing/` — OpenCV labs: thresholding, grayscale, padding, intensity transforms, spatial filters.
- `Feature Extraction/` — PCA, LDA, SVM on iris; `data/` has the movie/user csvs used by SVM.
- `Regression/` — regression labs.
- `PLANNER.md` — study plan and backlog tracker.
